Runtime facts represented here

The map stays within repository evidence. It does not infer retention, analytics, or provider behavior beyond the code paths named below.

  • Microphone data is transformed into 16-bit PCM chunks before WebSocket delivery.public/audio/pcm-capture-worklet.js
  • The client calls separate routes for refinement, notes, and excerpt assistance.app/lecture-translator/page.tsx
  • Routes authenticate before consuming Qwen services and record or enforce usage.app/auth.ts
  • Current workspace and optional saved lecture audio live in IndexedDB.app/lecture-translator/storage.ts
  • The Worker handles the realtime upgrade and delegates normal requests to Vinext.worker/index.ts
  • Cloudflare configuration supplies the DB binding and Vite loads the Worker stack..openai/hosting.json · vite.config.ts
